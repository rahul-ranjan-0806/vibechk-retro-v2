Chairman's verdict

Where the council agrees

  • Slash commands are the wrong primary pattern for this user. 4 of 5 converged independently. Non-technical founders using the product six times a week won't memorize cryptic verbs invoked behind two power-user gestures (⌘K then /).
  • /sources is the one command that earns its keep. Every advisor singled it out — connectors are a structured-input picker without a natural home in the UI.
  • Most current commands duplicate UI that already exists. /threshold lives on the leniency slider. /triage IS the home page. /draft belongs on the candidate row.
  • The Alt's NLP layer should carry the load slash commands paper over. If it can run live pre-screening interviews, it can parse "draft a rejection for Tom."

Where the council clashes

Kill vs. prune vs. expand. Kill (Contrarian, First Principles) takes the strongest stance: the menu undermines the AI's premise. Prune (Executor) is the only path with a falsifiable plan. Expand (Expansionist) sees a missed product opportunity but designs for a power user this segment doesn't have. The disagreement maps cleanly to belief about how the user evolves — six-times-a-week today, daily-driver tomorrow?

Blind spots peer review caught

  • The "Sabu" / "the Alt" naming collision. CLAUDE.md is explicit: the agent IS the Alt — "Sashank's Alt suggests…" not "the system suggests." Calling the overlay "Sabu" introduces a second named entity, fracturing the identity model the agentic architecture rests on.
  • Sabu's surface competes with AGENTIC.md's three-surface model (inline confirmations, ambient drawer, background activity log). A global Cmd+K overlay is a fourth — and most prominent — surface. Founders now have four places to find Alt's output.
  • No mobile/touch story. Slash menus and Cmd+K are keyboard-only patterns. Founders triage on phones between meetings; the whole flow dies on touch.

The recommendation

Side with the Executor's path, anchored to the First Principles reframe.

  • Cut now (no instrumentation needed — no defensible job): /export, /calibrate, /criteria, /triage, /draft. Each duplicates a UI affordance the founder is already on the page for.
  • Keep /sources but reframe it as a chip/@-mention attachment in the input. It's a parameter picker, not a verb.
  • Keep /memory for now — discrete write action, benefits from being explicit. Re-evaluate after instrumentation.
  • Add /candidate (or @candidate) — fuzzy-pick a person to scope the conversation. The one verb that addresses a real gap.
  • Ship instrumentation this week. Log every slash invocation, every Sabu query without one. Two weeks of behavior beats five advisors' opinions.

Do not build the Expansionist's spellbook — the user segment can't carry it. Re-open only if data shows founders returning to Sabu >5×/day. Address bigger structural bugs in parallel: rename the overlay so the Alt speaks (drop "Sabu"), and decide whether the Cmd+K surface collapses into or replaces the three agentic surfaces in AGENTIC.md.

The one thing to do first
Ship instrumentation on the Sabu overlay this week. Log every slash invocation, every prompt, every open-without-query. Don't redesign the menu before you have two weeks of data — cuts and additions become falsifiable instead of opinions.

Advisor responses

The Outsider Hide as accelerator

Slash commands are a power-user pattern. You're shipping them to non-technical founders. That's the whole problem in one sentence.

"Sabu" — what is this word? Why isn't it just "Ask Alt"? You already have a character (the Alt). Now there's a second named thing? I'd be lost in 30 seconds.

Cmd+K — non-technical founders don't know this shortcut. The slash commands themselves read like internal jargon: /triage (medical?), /calibrate (calibrate what?), /threshold (of what?), /sources (of what?), /draft, /compare. A founder hiring their first engineer types "/", sees seven cryptic verbs, and closes the panel.

Founders don't want commands. They want to type "show me the three best candidates for the backend role" and have it work. Keep slash commands as a hidden accelerator for the 5% who discover them. Don't design the primary interface around them.

The Expansionist Build the spellbook

Slash commands are a massive underplay. You've built the scaffolding for an agentic OS for hiring and you're treating it like a search shortcut menu.

The real opportunity: slash commands become the founder's API to their own taste. Stop thinking "command palette," start thinking "spellbook the founder builds over time."

Missing high-value commands:

  • /remember — promote anything in current view into Alt memory
  • /why — explain Alt's last decision (trust-building is your moat)
  • /pipeline — cross-role view; founders think about humans, not roles
  • /clone — duplicate a role's config
  • /intro — draft a warm intro to a shortlisted candidate
  • /standup — Alt summarizes everything since last login (daily ritual)
  • Custom slash commands users save → marketplace, moat that compounds per customer

Surface commands as ghost suggestions inline so non-technical users discover power. Slash commands are the substrate for the Alt becoming an actual operating partner. Build for that ceiling.

The Contrarian Kill the menu

Slash commands are wrong for this audience and you're about to learn it the expensive way. The single most "I am a power user" pattern in software — discovery requires typing a punctuation mark on a hunch. You're importing a developer-tool pattern into a product whose pitch is "you don't need to be technical."

Worse: stacked inside Cmd+K (also power-user). Path to your second-most-prominent feature: memorize a shortcut, then a punctuation trigger, then nine cryptic commands.

Every command listed is a thing the page should already surface. /threshold belongs on the leniency slider. /compare belongs on candidate selection. /draft belongs on the row. /triage IS the home page. You're building a parallel surface that duplicates the UI — two places to keep in sync.

/sources is the only one that earns its keep. Kill the slash menu. Let Sabu be conversational. The Alt is supposed to understand intent — make it do that instead of giving people a CLI in a trench coat.

The Executor Prune + instrument

Slash commands are wrong for this user. Founders at 8-person startups don't memorize command palettes — they type "show me Priya's interview" and expect it to work. Cmd+K overlay is fine; the slash menu inside it is engineering theater.

You've already built it, so don't rip it out — prune hard and let usage decide.

Kill immediately:

  • /export — nobody opens Sabu to export
  • /calibrate — too vague
  • /criteria — overlaps with the kanban
  • /draft — should just happen when you ask

Keep:

  • /sources — genuinely needs structured input
  • /compare — real verb that benefits from a picker UI
  • /memory — discrete write action

Add: /candidate (or @candidate) — fuzzy-pick a person.

Concrete next step: ship instrumentation this week. Log every slash invocation and every Sabu query that doesn't use one. In two weeks you'll know which commands are <2% of usage and can cut them with data, not opinions.

The First Principles Thinker Reframe + @-mention

You're asking the wrong question. The real question isn't "are slash commands the right pattern" — it's: why does a dashboard built around a natural-language Alt need a command palette at all?

Sabu's premise is that the Alt understands intent. If your NLP layer is good enough to run pre-screening interviews, it's good enough to parse "draft a rejection email." Slash commands are an admission that you don't trust your own AI.

Founders use the product six times a week, not sixty times a day. The cost of learning eight context-dependent commands exceeds the time saved.

Slash commands are doing two distinct jobs:

  • Discoverability — solve with a one-time inline hint or rotating placeholder.
  • Precision invocation of structured actions — /sources picking a connector. That's a parameter picker, not a command. Belongs as a chip-style attachment inside the input, like Linear's @-mentions.

Kill the slash-command framing. Keep /sources as a true picker. Make everything else just talking.
